# Обучение модели «работа / семья»

Скрипт учит небольшую нейросеть отличать рабочие фото (стройплощадка, люди в касках, конструкции, грунт, ограждения) от семейных (родственники, дети, питомцы) по **вашим** фото. Документы определяются правилами в самом приложении, для них обучение не нужно.

Всё происходит на вашем компьютере. Скрипт **только читает** фото из указанных папок, ничего не копирует и никуда не отправляет. Исключение: при первом запуске он скачивает с серверов Google готовую основу сети (MobileNetV2, ~10 МБ, без ваших данных). Если корпоративная сеть это блокирует, см. «Если что-то пошло не так».

## Перед запуском

1. **Проверьте папку «Семья».** Папка `C:\Users\yangirov\Documents\Фотографии` должна содержать только семейные снимки. Если там есть сканы документов, скриншоты, рабочие фото, модель научится на них ошибаться. Вычистите лишнее или создайте подпапку только с семейными фото и укажите её.
2. **Папка «Работа»** (`...\11 ОС РАСКОЛЬНИКОВА\РАСК1\ФОТО`) охватывает один объект. Для первого запуска нормально, но на фото другой площадки модель может ошибаться чаще. Со временем добавьте примеры с других объектов.
3. Нужен **Python 3.10–3.12**. Проверка: `python --version`. Если не установлен и прав на установку нет, напишите обращение в service-desk (Python нужен для обучения модели распознавания фото).

## Запуск (PowerShell)

```powershell
cd путь\к\PhotoSorter\training
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt

python train_model.py `
  --work "\\fs.talan.udm.ru\Общие документы\Обмен\БАЗА ЧЕЛНЫ +\11 ОС РАСКОЛЬНИКОВА\РАСК1\ФОТО" `
  --family "C:\Users\yangirov\Documents\Фотографии"
```

Если PowerShell не даёт активировать окружение (ошибка про политику выполнения), выполните один раз `Set-ExecutionPolicy -Scope Process Bypass` и повторите.

Обучение на 800 фото занимает порядка 10–30 минут на обычном ноутбуке без видеокарты.

## Что скрипт выведет

- **Точность на проверочных фото**, которые модель не видела, и матрицу ошибок: сколько рабочих фото принято за семейные и наоборот.
- **Таблицу порогов**: если требовать уверенность не ниже 0,85, модель возьмёт столько-то процентов фото и в таких-то процентах не ошибётся. Остальное приложение отправит в «Другое». По этой таблице выбирается порог для «Работы» (`workMin` в `Rules.kt`, сейчас 0,85) и для «Семьи» (`familyMin`, сейчас 0,70).
- Файлы `out\photo_model.tflite` и `out\photo_labels.txt`. Скопируйте оба на телефон в папку `Pictures/PhotoSorter/_model` (папку создайте сами; по USB или через «Мои файлы»). Пересобирать приложение не нужно: модель подхватится при следующем проходе сортировки. На экране приложения должно появиться «Модель распознавания: подключена».

## Как улучшать

- Хорошая точность на проверке не гарантирует хорошую точность в жизни: в проверку попали снимки того же объекта и тех же людей. Реальный результат покажет журнал приложения за первую неделю.
- Фото, которые ушли в «Другое» или в неверную папку, разложите по трём папкам на компьютере и запустите обучение заново. Добавьте и папку примеров «другого» (`--other`): мемы, еда, скриншоты чатов, всё, что не работа и не семья. С ней модель перестанет насильно записывать посторонние снимки в «Работу» или «Семью».

## Если что-то пошло не так

- **Не скачиваются веса сети** (ошибка про `storage.googleapis.com`): напишите в service-desk с просьбой разрешить этот адрес на время обучения, либо запустите скрипт на домашнем компьютере (фото рабочего объекта тогда придётся копировать туда, это решение за вами).
- **В классе меньше 20 фото**: проверьте путь и доступ к сетевой папке (откройте её в проводнике).
- **Ошибка «TFLite-модель расходится с исходной»**: файлы не использовать, пришлите текст вывода.
