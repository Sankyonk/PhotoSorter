# PhotoSorter

Android-утилита (целевой телефон: Samsung Galaxy Z Flip 7, Android 16): новые снимки из камеры и скриншоты **перемещаются** в четыре папки.

| Папка (в `Pictures/PhotoSorter`) | Что попадает |
|---|---|
| `Работа` | Стройплощадка: люди в касках, конструкции, грунт, ограждения |
| `Документы` | Фото и сканы листов, чертежи, планы, личные бумаги |
| `Семья` | Родственники, дети, питомцы |
| `Другое` | Всё, что не удалось уверенно отнести к остальным |

Срок: в течение ~5 минут после появления снимка. Мессенджеры не обрабатываются (у них свои папки). Всё считается на телефоне, фото никуда не отправляются.

## Как определяется папка

1. **Документ.** Светлый лист и много текста или тонких линий (правила, ML Kit Text Recognition). Проверяется первым: фото паспорта с портретом остаётся документом.
2. **Работа / Семья.** Небольшая нейросеть, обученная на ваших фото (`training/`). «Работа» принимается при уверенности от 85 %, «Семья» от 70 %.
3. **Иначе «Другое».** Нет модели в приложении или она не уверена. Пока модель не обучена, приложение определяет только документы, всё остальное уходит в «Другое».

        │       │   ├── Category.kt          — четыре категории и имена папок

        │       │   ├── PhotoAnalyzer.kt     — текст (ML Kit) + линии/белизна + модель → Scores
        │       │   ├── PhotoClassifier.kt   — запуск обученной TFLite-модели
        │       │   ├── ImageStatsCalculator.kt — «белизна листа» и плотность линий

## Источники

`DCIM/Camera/`, `DCIM/Screenshots/` (Samsung) и `Pictures/Screenshots/` (на случай другого расположения). Список — в `Prefs.sourceFolders`. Старый архив галереи не трогается: при первом включении запоминается текущее время, сортируются только новые снимки.

## Что нужно знать

- **Доступ ко всем файлам** (`MANAGE_EXTERNAL_STORAGE`): без него Android 11+ спрашивает подтверждение на каждый перенос. Из-за этого приложение не пройдёт Google Play: раздавать как APK или через MDM.
- **Samsung.**
  - Установка APK: «Автоблокировщик» (Настройки → Безопасность и конфиденциальность) блокирует установку из неизвестных источников; на время установки его нужно выключить. Play Protect может предупредить о неизвестном приложении.
  - Фон: Samsung усыпляет приложения. В настройках батареи для PhotoSorter выберите «Без ограничений» и уберите его из «Спящих приложений».
- **Срок 5 минут** обычно выполняется (1,5–3 мин), но не гарантирован: Doze и ограничения One UI могут отложить запуск. Если не хватит — режим со службой переднего плана (постоянное уведомление).
- **Скриншоты.** Светлый скриншот переписки с большим количеством текста правила могут принять за документ. Если так будет, добавим отдельное правило для скриншотов.
- **Пороги стартовые**, не проверены на ваших фото (`Thresholds` в `Rules.kt`). Журнал показывает по каждому снимку признаки и ответ модели — по нему пороги настраиваются.
- Файл модели (`photo_model.tflite`) обучен на личных фото, поэтому в `.gitignore` и в репозиторий не попадает.

## Сборка APK на GitHub (без Android Studio)

1. Распаковать архив. Завести на github.com приватный репозиторий (Create a new repository → Private).
2. В репозитории: `Add file → Upload files`, перетащить **содержимое** распакованной папки `PhotoSorter` (вместе с папкой `.github` и файлом `.gitignore`), нажать `Commit changes`.
3. Вкладка `Actions`. Сборка запускается сама после загрузки; вручную: `Build APK → Run workflow`. Занимает 5–10 минут.
4. Открыть завершённую сборку, внизу в разделе `Artifacts` скачать `PhotoSorter-debug-apk`, распаковать: внутри `app-debug.apk`.
5. Если сборка красная: открыть шаг, который упал (красный крестик), скопировать текст ошибки и прислать Claude.

Новые версии: загрузить изменённые файлы в репозиторий, и сборка пройдёт заново. APK подписывается одним и тем же ключом, поэтому ставится поверх старой версии. Ключ в репозитории учебный (debug), для личного использования достаточно.

Установка на телефон: перенести `app-debug.apk` и открыть. Samsung может потребовать отключить «Автоблокировщик».

## Модель

Обучить модель (`training/README.md`). Результат, два файла `photo_model.tflite` и `photo_labels.txt`, скопировать на телефон в папку `Pictures/PhotoSorter/_model` (папку создать). Модель обучена на личных фото, поэтому в APK и в репозиторий она не попадает. Заменить модель можно в любой момент без пересборки приложения. Без модели приложение определяет только документы.

## Тесты

Автопроверки правил (`RulesTest`) запускаются на GitHub в той же сборке; результат виден в шаге «Автопроверки». Локально: `./gradlew :app:testDebugUnitTest`.

## Что дальше

1. Неделя работы → разобрать журнал, добавить ошибочные фото в обучение, подогнать пороги.
2. Кнопка «Отменить последнее перемещение» (журнал уже хранит старый и новый путь).
3. Экран настроек: исходные папки, пороги.
